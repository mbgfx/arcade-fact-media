The Konami Code exists because a developer found his own game too hard. 🕹️

Kazuhisa Hashimoto created Up Up Down Down Left Right Left Right B A while porting Gradius to the NES, because he couldn't beat it in testing. It was meant to be removed, but slipped through and was kept.

🔎 Bonus: The code later became famous with North American players thanks to the NES version of Contra.
